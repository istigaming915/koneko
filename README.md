# 🐾 Koneko - Dein ultimativer Discord-Begleiter

Koneko ist ein vielseitiger Anime-Bot, inspiriert von Nekotina. Er bringt Spaß, Wirtschaft und soziale Interaktion auf deinen Server!

## ✨ Features (Module)
Wie in den Vorlagen zu sehen, bietet Koneko alles, was eine moderne Community braucht:

*   **Social Commands:** Interaktive Befehle wie `!hug`, `!pat` und `!slap` mit süßen Anime-GIFs.
*   **Economy System:** Sammle tägliche "Pfoten-Coins" mit `!daily` und baue dein Vermögen auf.
*   **Discord Activities:** Voll kompatibel mit dem neuen Discord-Activity-Regal (Hintergrund-Overlay & Cover-Artwork vorhanden).
*   **Leveling:** Belohne aktive Mitglieder deiner Community automatisch.

## 🖼️ Assets & Design
Das Design orientiert sich an einem modernen Pastell-Look (ähnlich wie in Datei **697bfb9e-ae0c-41d5-8ab8-f62adc051fbb**).
Die Grafiken im Ordner `/assets` entsprechen den Discord-Vorgaben:
*   **Hintergrund-Overlay:** 1024x576 (Rasteransicht)
*   **Cover-Artwork:** 1024x576 (Aktivitätenregal)
*   **Vorschau:** 640x360 (Videovorschau)
